# v0.3.0 · ESP32 实物相机台架

根据已到货的 ESP32-S3-N16R8 / OV5640 增加实物相机页面，保留原有模拟任务和只读回放。STM32 尚未到货，真实飞控通信、动作和飞行仍未完成。

- 新增「ESP32 实物台架」：通过热点读取真实 JPEG、固件、尺寸、PSRAM、相机流编号、UDP 校验计数和自动对焦状态，支持重新对焦。
- 已在本机配对 ESP32 的 0.1.4 台架固件上验证 800×600 JPEG 显示与对焦命令；AF 是否完成按传感器回报显示。画面清晰度、噪点、光学采集时序和标定仍需独立验收。
- 实物预览检查身份、请求/帧/流、递增时间、用途标记、尺寸和 JPEG 解码。64 位编号保留十进制字符串。显示不授予视觉控制资格，不修改协议 ImageGate。
- 实物连接中断模拟；打开回放关闭实物输入，退出不自动重连。流变化、断线、后台失效和迟到图像使画面失效。飞控测量保持未知，动作出口关闭。
- 保留 S0–S2 的固定模拟任务、权限/结果语义、有界录制与回放、原协议受控副本，以及独立 Windows 运行时。

Windows 下载 **LF2S-Station-0.3.0-win-x64.zip**，完整解压后打开 `LF2S-Station.exe`。无需另装 Node/Python，必须保留整个目录。电脑先连接 ESP32 热点（本次配对板为 `LF2S-S3-81E5`），再在软件中连接 `192.168.4.1:80`；USB 用于供电。需要 0.1.3 及以上的 0.1.x 相机台架固件。热点密码和固件镜像不随本上位机发布包提供。

附带 ZIP SHA-256、逐文件清单和解压后桌面运行验证 JSON。软件回归与真实板显示测试分开记录在包内验收报告；原始实拍、私有网络配置、机载固件及厂商资料不随包发布。

这是预览版本，未签名、无安装器；另一台干净 Windows、STM32/UART/NRF、语音/视觉模型、相机标定/新鲜度、机载故障处置和飞行未验收。STM32 源码适配与接线实测按用户决定等待到货，S3 整体与 S4–S5 尚未完成。
