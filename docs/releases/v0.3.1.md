# v0.3.1 · 修复 ESP32 预览误判断线

修复 v0.3.0 中 SVGA 图像传输稍慢就永久显示“连接已失效”的问题。同一实板已复现：热点仍连接，但 2 秒强制截止中止预览，随后软件停止恢复。

- 预览读取期限调整到 6 秒，状态与对焦保持独立期限，响应大小和绝对截止继续受限。显示慢图不产生相机标定或新鲜度资格。
- 临时传输异常时清除旧画面、显示恢复状态，最多核对三次同一相机流后继续预览。连续失败、重启/流变化或身份/JPEG 错误仍需手动重连；对焦和动作不自动重发。
- 增加传输异常/恢复次数、错误耗时与原因日志，修正实物日志来源和窗口标题。
- 保留模拟任务、只读回放及与实物隔离。ESP32 固件继续使用 0.1.4，无需为本修复重新烧录；STM32 未接入，飞行动作关闭。

下载 **LF2S-Station-0.3.1-win-x64.zip**，完整解压并打开 `LF2S-Station.exe`。附 SHA-256、逐文件清单及 ZIP 解压运行验证 JSON；验收与稳定性记录见包内 evidence 和 docs/07。热点使用方式及密码沿用原配置。

本版仍为预览版；短时持续测试不等于长期 Wi-Fi、供电/散热、相机光学时序、STM32/UART 或飞行验收。
