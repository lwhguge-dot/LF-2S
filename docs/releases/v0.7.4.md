# 0.7.4 飞控协议状态诊断

之前，后台收到了FAULT及其原因，监控总览却只显示链路和测量；“链路在线、测量未知”不能直接说明飞控上报了什么。本版新增只读诊断卡，显示上报模式、上报原因、预检、人工接管锁存、控制者编号及租期/任务。

SENSOR显示“传感器数据条件未满足”，不会推断为特定MPU、光流或供电故障。模式和原因来自当前会话CONTROL_STATE，不是动作执行证明。原因OK显示“未上报失效原因”；0值不会当未知。未识别枚举显示原编号，保留协议兼容诊断。预检来自上报位，所有真实控制资格继续关闭。

只在当前链路有效时展示。超过既有1000ms应用链路预算、校验阻断、飞控重启、显式断开、回放、相机/USB台架切换时，相关值全部清空为未知。前端超过既有1500ms未收到后台更新也独立屏蔽旧值；这些预算没有新增实机控制指标含义。录制中的历史报告仍属历史，不替代实时状态。

没有增加动作、许可、裸协议转发、串口或硬件控制出口。状态包没有解锁字段，因此卡片不显示推断解锁状态。原人工锁存及0.7.3重启后显式重连规则保留。

新增后台测试从保存的85C TIM1/主循环场景回放24帧C字节，并核对故障和权限清除；I2C、定时器、本地源仍是显式软件夹具。桌面检查通过本机模拟任务制造传感器失效，验证中文显示、过期、人工锁存、回放与服务退出；不是ESP32/STM32实机测试。逐项执行结果见evidence/acceptance.json和desktop-dev/package/archive报告。

旧0.7.3源、测试、文档与证据保存在`evidence/history/v0.7.3`，原目录包和ZIP保留。本版不继承旧实物USB、ESP32或公司API结果为新版实测；语音依旧普通话优先，固定qwen38且关闭思考，公司ASR与真人准确率仍待部署/评测。
