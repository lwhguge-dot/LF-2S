# v0.8.1 · 矮窗口调试导航

修复 Windows 窗口较矮时固定侧栏底部导航被挤出可视区域的问题。调试导航现在可在侧栏内滚动，并增加 720px 高度下的实际 Electron 回归。

本机已重新验证后台、桌面窗口、视觉任务工作台、独立运行目录与解压 ZIP。GitHub Windows CI 将在候选提交推送后运行；通过后才发布预览。此维护版本不增加真实视觉、UART、飞行动作或硬件验收；演示灯具、斑马线和收银台仍未准备。

完整运行包为 `LF2S-Station-0.8.1-win-x64.zip`，包含自带运行时；下载并解压后运行 `LF2S-Station.exe`。版本资产和 SHA-256 随 GitHub 预发布说明提供。
