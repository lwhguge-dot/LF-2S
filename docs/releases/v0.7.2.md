# 0.7.2：电脑热点与ESP32网络诊断

之前页面仍要求电脑连接板卡热点，无法说明电脑热点STA模式，也没有显示DHCP地址和信号。现在连接前填写实际ESP32地址，页面按0.1.6固件报告显示连接方式、IPv4、RSSI和信道；旧固件未提供的字段保持未知。热点重开后可按电脑设备列表或串口核对新地址，程序不扫描网段、不切换电脑Wi-Fi，也不按板卡返回的地址自动重定向。

网络字段经过类型、数值范围和局域网地址校验，SSID／密码不进入渲染层。网络代数只作板卡诊断，不当作飞控boot／会话、控制权或物理图像资格。原0.7.1撤权后零租期终结结果修复保留；没有新增实际飞行动作出口。

验证以本版执行报告为准：后台测试、开发／目录包／ZIP解压桌面检查，以及显式ESP32实物台架分别记录。语音界面回归使用测试麦克风和模拟ASR；公司语音仍未部署，真实普通话准确率与飞行未验收。0.7.1的运行包、完整性记录和源快照保留为历史证据。

本轮ESP32实物流程仍观察到HTTP超时，开发版和目录包的完整实物套件未通过；失败原始记录已保留，软件回归通过不覆盖这些失败。测试脚本另修正了“本来已是目标尺寸时提前通过”的等待竞态，必须同时看到新流；未放宽超时或自动重发设置。当前不宣称长期图传稳定性已解决。
