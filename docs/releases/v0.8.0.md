# v0.8.0 · 视觉任务工作台

打开软件现在直接进入明亮工作台：相机大画面在左侧，当前任务和识别结果在右侧，底部集中输入文字或核对语音。原有ESP32参数、飞控USB、协议诊断、模拟任务、回放和日志从「设备与调试」进入。

新增过路、寻找路边或收银台、清点平铺人民币纸币和信号灯查询的任务建议。例如「去B点」只生成寻找收银台建议，「看看B点一共有多少钱」才进入纸币清点建议。场景按钮只填入原文，点击解析后才调用关闭思考的 `qwen38`；修改原文、切页、取消、回放或服务失效会清理旧建议，迟到回复不会覆盖新原文。

当前生成的是待审阅流程。实时灯况、闪烁、斑马线、纸币张数/面额/总额保持未知。视觉自主搜索、实景识别、纸币计数、轨迹与飞行执行尚未接入；公司语音服务未部署。大画面与文字建议不生成识别结果或飞机控制许可。

本版同时公开此前本机构建加入的原厂飞控USB只读观察、普通话录音/导入与转写核对、无思考文字建议、热点STA诊断、撤权结果关联及飞控重启/协议状态诊断。既有合成任务、日志与只读回放继续保留。旧实物记录按原版本保留，不计为0.8.0实机复测。

验证使用实际Electron/Python/IPC与独立运行包：后台回归、原调试流程、新工作台、测试麦克风/模拟ASR分别记录；实际公司文本调用单独记录。ZIP另行解压并运行，逐文件清单、SHA-256和实际结果随发布资产提供。这些检查不代表灯具/纸币/真人普通话/真实UART或飞行通过。具体成绩见包内 `evidence/验收报告.md`、`workbench-public-summary.json`、`text-public-summary.json` 和发布的 `verification.json`。

下载完整 `LF2S-Station-0.8.0-win-x64.zip` 并解压，运行其中的 `LF2S-Station.exe`，无需安装Python或Node。公司接口配置使用包内 `Start-CompanyModel.ps1`；访问凭据只经进程环境传入，不在发布包中保存。详情见 `docs/12_视觉任务工作台.md`。
