# v0.2.0 · S2 模拟任务与只读回放

本版在原只读监控上增加固定模拟任务和记录回放，全部在本机模型中运行。没有连接真实无人机，也未完成 S3–S5 或实机飞行验收。

- 显式准备任务模拟器后，每次确认许可，经 PERMIT → ACQUIRE → BEGIN → 模拟起飞至 0.50 m → 保持 → 降落上锁 → END → RELEASE。
- 接受、进行中、动作完成与任务完成分开；完成依赖新的有效合成样本。断链、传感器冻结、定位重置、人工接管和重启中断流程，旧动作不自动恢复。
- 原字节/原编号有限重试；未知结果只查询原请求。人工接管锁存，普通重连不能解除。
- 有界事件和状态录制、时间轴定位与播放。回放断开实时会话，禁止发送控制；保留完整 u64 编号、有效性、来源和结果。JPEG 只记元数据，不混用实时图像。
- 保留中文监控、未知/null、来源/指纹校验、合成 JPEG、单实例、后台重启与退出清理。

Windows 用户下载 **LF2S-Station-0.2.0-win-x64.zip**，完整解压并打开 LF2S-Station.exe。无需另装 Node/Python；保留整个目录。Source code 仅为源码。ZIP 附带 SHA-256、逐文件清单与解压后运行验证 JSON，验收范围见包内 evidence/验收报告.md。
