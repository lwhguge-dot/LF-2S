# v0.4.0 · 改善 ESP32 图传刷新并显示实际帧率

连续预览每次只处理一张图，可选上限 10/5 FPS 或 1 FPS 静态查看；界面显示实际显示 FPS、请求至显示耗时、JPEG 大小与板端等帧时间。复用有限 HTTP 连接，减少反复建连，异常后保留原流核对与有界恢复。

配合 0.1.5 相机台架固件，可在 320×240、640×480、800×600 及自动/室内白平衡之间切换。参数设置核对新代数、尺寸、量化值和模式；不明确的设置结果须手动重连，不自动重发。内部测试图不能充当真实场景。

本机持续图传与真实桌面数据见包内 `evidence/preview-performance-summary.json`，测量方法和限制见 `docs/08_图传帧率与画质.md`。上限不保证达到，帧率与物理曝光时延、光学清晰度和识别率分别评估；1 FPS 适用于静态查看。STM32 未接入，飞行动作保持关闭。

下载 **LF2S-Station-0.4.0-win-x64.zip**，完整解压后打开 `LF2S-Station.exe`。附 SHA-256、逐文件清单及解压运行验证 JSON。软件包不包含板卡热点凭据、室内原始照片和机载固件；台架固件与原始证据留在本机开发目录。
