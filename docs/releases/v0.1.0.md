LF-2S 首个开源桌面预览版，范围为 **S0–S1 只读本机模拟**。这不是全部无人机系统完成，也不是实机或飞行验收。

下载 `LF2S-Station-0.1.0-win-x64.zip`，完整解压后打开文件夹中的 `LF2S-Station.exe`。无需另装 Node 或 Python；不能只取出 exe。下载旁边的 `.sha256` 可校验 ZIP，`.manifest.json` 提供包内逐文件哈希，`.verification.json` 记录解压后实际桌面验收结果。

本版包含中文状态面板、协议配置查询、合成 JPEG、事件日志、明确的模拟/未知/过期提示。通过真实 localhost HTTP/UDP 复用已有 MAVLink 2；64 位编号从线协议到界面保真。仅有只读连接与查询，没有解锁、起飞和任务入口。

验证包括 Python 后台 13 项测试、开发窗口和打包窗口各 24 个检查点，以及 ZIP 解压后的整组桌面验收；覆盖断链、传感器过期、错误来源/指纹、后台重启、单实例与正常/异常退出清理。重复运行同一组检查不代表增加业务能力。

已在当前 Windows 11 x64 主机验证。未完成另一台干净主机、安装/升级/卸载、数字签名、真实 ESP32/STM32/UART/NRF、真实相机、中文语音、视觉模型或飞行验证。软件未签名。

后续路线：模拟任务闭环与回放 → 真实 ESP32/STM32 主线 → 独立图像、中文语音和视觉 → Mind+ 经手柄/NRF 补充线。保留商家飞控内环和原遥控人工接管。
