# 应用接口与进程生命周期

Electron 是窗口和进程宿主；Vue 不持有网络、串口或凭据。Python/FastAPI 是唯一车辆连接所有者，单 Uvicorn worker、无 reload。合成 JPEG 在有界单请求线程任务中生成，不在 UDP 调度循环压缩图像；后续 AI 使用独立进程，不能阻塞协议调度。

## API v1

全部路径以 `/api/v1` 为前缀，只绑定动态 127.0.0.1 端口。每次启动随机 256 位 token，通过子进程 stdin 私有引导传递；请求用 Authorization Bearer。Host 必须匹配绑定的 IP/端口，带任意 Origin 的请求拒绝，不启用 CORS。token 不在参数、URL、文件、日志或渲染进程中。此凭据只保护本地服务，不为 MAVLink 无线链路提供加密鉴权。

| 方法 / 路径 | 请求 | 返回 |
| --- | --- | --- |
| GET /health | 无 | ready、api_version、pid、frozen、simulation=true、hardware_control_allowed=false、read_only=false（服务支持模拟任务） |
| GET /state | 无 | docs/01 中的完整快照、最近日志、只读操作 |
| POST /connect | 无或空 JSON；额外字段拒绝 | HELLO 操作结果；重复连接拒绝 |
| POST /disconnect | 无或空 JSON | 清除当前 Client/测量/配置，失效未完成请求 |
| POST /profile | 无或空 JSON | 串行 QUERY_PROFILE，关联 RESULT 与当前配置 |
| POST /simulation/scenario | `{ "name": "sensor_freeze" }` 等固定枚举 | 场景名；额外字段拒绝 |
| POST /tasks/start | `{ "confirmed": true }`，严格布尔值和固定示例，无额外参数 | 后台任务状态；新样本与最终结果驱动完成 |
| POST /tasks/cancel | 无或空 JSON | 停止推进和续租，经原协议取消任务 |
| POST /tasks/query | 无或空 JSON | 只查询原会话、原 request_id；不继续旧流程 |
| GET /recordings | 无 | 有界录制列表及容量/丢弃/写入错误 |
| POST /replay/open | `{ "recording_id": "24位小写hex", "index": 0 }` | 断开实时会话并返回历史帧 |
| POST /replay/seek | 同 open | 只读取历史帧与此前最近 60 条事件，不发协议请求 |
| POST /replay/close | 无或空 JSON | 退出回放，保持断开 |
| GET /events?after=0 | 可选递增游标 | 最近事件、最新游标、最早可用编号、丢弃数 |
| GET /image | 无 | 有界 image/jpeg，合成标记、u64 流号字符串、u32 帧号；非在线返回 409，并发 429 |
| POST /bench/connect | `{ "host": "192.168.4.1", "port": 80 }`，额外字段拒绝 | 断开模拟后读取实物状态；RFC1918 IPv4 字面值，无主机名/重定向 |
| POST /bench/disconnect | 无或空 JSON | 失效当前实物 epoch、状态和图像 |
| GET /bench/preview | 无 | 最大 256 KiB 的已解码校验 JPEG；synthetic=0/display-only=1/qualified=0 |
| POST /bench/focus | 无或空 JSON | accepted 表示请求接受，不表示对焦完成；回放拒绝 |
| POST /bench/settings | `{ "size": "vga", "colour": "driver" }`；size 仅 qvga/vga/svga，colour 仅 driver/office，无额外字段 | 仅未标定显示参数；核对下一代流/尺寸/量化值，超时不重发，回放拒绝 |

未知路由 404；业务冲突 409；认证失败 401；不允许的来源 403；字段错误 422。API 没有通用 URL 代理、文件执行、任意 MAVLink 发送或任意动作端点。固定模拟任务只能经后台 TaskService；回放期间连接、配置、任务、场景和图像均返回 409。请求体最多 4 KiB，主进程响应最多 2 MiB，图像最多 1 MiB。界面依赖 HTTP v1 和限频 IPC 快照推送，目前没有 WebSocket 协议。单个快照轮询结束后才安排下次，250 ms 一次，无重叠轮询。

`DesktopBridge` 类型定义位于 `frontend/bridge.ts`。preload 仅提供 state/connect/disconnect/profile/scenario/image/restart/openLogs/onState 及固定的 taskStart/taskCancel/taskQuery/recordings/replayOpen/replaySeek/replayClose；不暴露 ipcRenderer、token、通用路径或 socket。主进程检查窗口、主 frame 与精确本地文档 URL。contextIsolation/sandbox/webSecurity 开启，nodeIntegration/webviewTag 关闭；禁止窗口跳转、弹窗、设备权限和外部页面网络资源。网页 CSP 禁止 connect 和远程脚本；Electron 主进程固定直连本地 HTTP，不继承系统代理选择目的地。

## 启动与退出

0.3.0 新增 `benchConnect/benchDisconnect/benchPreview/benchFocus` 四个窄 IPC 方法。实物 HTTP 独立于模拟 UDP，只提供图像与诊断；实物占用期间模拟端点拒绝，回放开启时失效实物 epoch。完整期限和图像语义见 docs/06。后台启动握手仍表示默认模拟通道可用，实际当前模式以 `/state.mode` 为准。

0.4.0 额外开放 `benchSettings(size, colour)` 窄 IPC，主进程和后端分别验证固定枚举，不暴露寄存器、测试图或任意 URL。JPEG 元数据新增 roundtrip_ms/decode_ms/camera_wait_ms；未知相机等待时间为 null，内部测试图拒绝进入实物场景。界面最多一个在途预览，调整设置先等待当前读取结束并失效旧图。

1. Electron 获取单实例锁，再创建窗口。启动失败也能显示中文错误，不留在空白屏。
2. 创建专属后台，随机 token + user_data 经 stdin 传递。Python 对该用户目录的 service.lock 做 Windows 排他字节锁，阻止直接重复后台。
3. Python 先创建独占 TCP 监听 socket，再启用 FastAPI lifespan 内的模拟端点；就绪后输出不含凭据的 JSON。Electron 校验版本、simulation/hardware_control_allowed=false/frozen 标记，再做 health 请求。
4. 页面初始断开，用户点击才 HELLO。重新连接总是构造新 Client，所有旧 challenge/task/reset/profile/测量失效。没有自动恢复动作。
5. 普通关闭：停止轮询，结束自有 stdin，等待后台退出，超时才终止这个自有子进程。后台停止任务和续租，关闭 UDP、日志、录制、HTTP、文件锁。
6. 主进程异常结束：后台独立监听 stdin EOF，触发相同清理；5 秒看门超时后结束自身。没有通过进程名杀其他程序。
7. 后台退出：主进程清空快照并报告服务错误，界面清除可用数据。用户可手动重启服务，但仍须显式连接新会话。

渲染页面刷新不会新建后台或重发协议操作。IPC 发布仅报告状态，不产生动作。后台超时/卡住时，主进程停止显示有效数据，用户可以通过「重启本地服务」恢复；正常软件退出不替代机载失联保护。

## 扩展入口

未来 WebBridge 必须实现同一类型并另行设计部署与认证；当前不是浏览器远程控制。S4 的真实图像 provider 应接现有 `image_http.py` 的有界读取和 ImageGate。S2 TaskService 已在后台实现固定模拟示例的权限、结果和期限检查；S3 真实设备仍需独立适配和验收。S4 的语音/视觉 worker 使用有界工作队列，仅返回候选意图，不持有 UDP 所有权或生成裸 MAVLink。
