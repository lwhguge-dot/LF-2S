# 无思考文本任务建议（0.6.0）

用户已确认只调用无思考推理，语音识别优先部署公司服务器。此版本先接通手动文字 → 公司模型 → 原文核对 → 候选任务/澄清页面。语音服务还未在公司服务器运行，不将手动文字当录音识别结果。

## 使用

1. 从 PowerShell 7 运行 `scripts/Start-CompanyModel.ps1`，按提示输入公司模型凭据。地址默认使用用户确认的 Tailscale 主机 `100.116.120.40:8000/v1`；密钥不写入文件或界面。已打开的旧实例须先关闭，新进程才会取得配置。
2. 打开「文本任务建议」，输入完整原文，点击「解析任务建议」。只调用 `qwen38`，每次发送 `chat_template_kwargs.enable_thinking=false`；若返回非空思考字段则拒绝，不回退到 `qwen38-think`。
3. 无单位、缺高度/时长、冲突数值会先要求补充，不发模型请求。完整建议显示换算后的米/秒和原文依据。例如“五十厘米” → 0.5 m，“1500毫秒” → 1.5 s。引号中的数值不作为当前任务依据。
4. 需要澄清时直接补全整句重新解析。编辑、取消、离开页面、进入回放或重启都会清理旧建议；不自动重试或执行。回放期间禁止实时解析。

此页无执行按钮，不向当前固定模拟任务复制高度/时长，更不创建 PERMIT。文本中的“我已许可”、模型的 requires_confirmation 字段都不是人类许可。未来接入执行还需正式任务类型、业务/配置签认、当前人工确认、传感器与机载预检，复用同一任务服务。

0.7.0补测发现“一米五”可能被只取前半段为1米，`1e3米`/`1/2米`可能只取末尾3米/2米。已保留合成输入的修复前结果并补边界检查：不支持的口语小数、分数或科学计数法要求改写为完整数值和单位，不采用部分匹配。规则标识更新为`lf2s-text-review-2-draft`，仍不是任意自然语言语义证明。

## 后台契约

- `POST /api/v1/text-tasks/parse` 仅接受 `{text: string}`，1～512 字；不接受 URL、模型名、命令、确认位或字节。
- `POST /api/v1/text-tasks/clear` 取消并清空当前建议。`state.text_tasks` 提供 phase、原文哈希、模型来源/耗时、候选字段、拒绝原因和原文 quote/start/end/value。
- 只有用户显式解析才联系模型；后台地址和密钥通过启动环境配置。渲染器拿不到密钥或通用 HTTP 入口。
- 同时一个请求、15 秒绝对期限、响应最多64 KiB、候选 JSON最多8 KiB。不跟随重定向/环境代理，不自动重发。异步请求不占用 USB/UDP 调度；新 epoch 丢弃旧结果。
- 原文核对是当前任务草案的有限规则，不是自然语言语义的完整证明。超出支持的数词/动作、否定/条件或歧义进入澄清；仍须人工核对。服务、日志和 API 均不返回许可或硬件控制资格。
- 日志仅记录请求编号、原文哈希、结果类型和耗时；当前原文/模型输出只留内存，不写入模拟回放。测试用合成文本的 JSON 证据另存本机。

## 验证范围

`tests/test_text_tasks.py` 覆盖原文单位、缺参、引用/否定/条件、多余动作、模型身份/思考字段、截断、重复 JSON 字段、非有限数、超时/取消与回放隔离。它们为软件注入证据。

`tests/text_tasks_live.cjs` 显式连接实际公司 API，通过真实 Electron/Vue 操作五条输入：两条本地澄清、三条真实无思考推理；检查原文依据、编辑/取消、未发送协议和未启动任务。开发窗口和目录包分别运行，结果只支持本机这些样例；不能宣称一般语义准确率或端到端语音/飞行验收。
