# 阶段验收与后续入口

本轮 S0–S1 的可复验项目：独立依赖/锁文件；类型与 Python 检查；受控协议副本；实际窗口到 HTTP/UDP 的 HELLO 和 PROFILE；中文状态、逐项年龄、未知/过期/来源/指纹原因；u64 全链路保真；JPEG 解码；日志展开与关联；单实例；后台重启、正常/异常退出清理；刷新不重放；离线本地页面；无开发环境 PATH 的 Windows 目录包。

自动流程与截图在 `tests/test_backend.py`、`tests/desktop.cjs`、`evidence/`。仅在当前 Windows 11 x64 主机实际运行，不推导为另一台干净机器已通过。页面网络被设为 offline 只验证本地资源/IPC，不等于实际拔网线、ESP32 Wi-Fi 干扰或无线时延验收。安装器、代码签名、升级/卸载、跨机与回退另列后续。

## S2：模拟任务闭环、日志与回放

- 先固定后台 TaskService 契约：现场确认 → 一次性 PERMIT → ACQUIRE → BEGIN → 受限动作。
- ACCEPTED/IN_PROGRESS 与 COMPLETED 分离；最终结果不被迟到接受覆盖；未知结果只查询原编号。
- 任务、目标、租期、challenge 与定位 reset 分别检查。断链/重启不恢复旧动作。人工接管优先且锁存，普通重连不能解除。
- 模拟生产者按有效新样本推动完成条件，不凭等待时间或 ACK 模拟成功。
- 回放通道只读，记录 session/请求/接收时刻/有效性/来源/结果；高频遥测与图像有容量、磁盘与丢弃策略。

## S3：真实 ESP32 / STM32 主线

- 先询问并核对到货、板卡完整型号、供电、电平、UART 引脚、Flash/PSRAM；不把 hello_world 的目标或示例容量当作硬件事实。
- 保留 `P1/03_esp32_idf/hello_world`，继续 VS Code + 官方 ESP-IDF；新建适配工程，保留商家内环和原遥控。
- 按协议 P2 交接实现 ESP32 UART/UDP 转发和 STM32 业务适配，先真实只读遥测，再满足条件的拆桨与飞行。
- 真实配置独立登记与签认，不能复制 simulation/profile.json。机载故障处置需独立验证；XY 无效不保证原地悬停，高度无效不保证定高。

## S4：独立图像、中文语音和视觉

- ImageProvider 替换为有界 HTTP JPEG + ImageGate，验证请求/帧/流/标定和真实新鲜度；显示成功不能直接开放视觉控制。
- 先问用户具体中文任务、现场噪声、联网条件、接口和时延目标，再选 ASR/LLM/视觉模型；国内可用、中文质量与离线能力优先。现有资源不是已选型号。
- 语音先转文字和候选任务，经确认和同一任务服务执行；AI 进程有界，不阻塞取消、期限和 UDP。

## S5：Mind+ 补充线

Mind+ 在电脑运行 → 有线手柄 → NRF → 飞控，接同一权限与结果模型；新 MAVLink 分片和原人工遥控严格分流，实测非阻塞双向调度和人工帧最大间隔。QGroundControl 兼容、多人/多机和远程浏览器按真实需求后续评估。
