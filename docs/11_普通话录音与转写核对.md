# 普通话录音与转写核对（0.7.0）

用户已确认普通话为主，中文优先，任务推理只用无思考 `qwen38`。此版加入录音/导入 → 试听 → 显式提交ASR → 核对/修改转写 → 填入任务原文 → 显式解析建议。任何步骤均不生成PERMIT、不启动任务、不向当前模拟任务复制数值。

公司语音服务尚未部署。Linux模型安装按研发工作区 `P1/09_语音服务/Linux终端部署.md`，不要求复制ZIP。下述入口已可对接独立HTTP接口，但本机样音/测试设备不能当作公司服务器、真人麦克风或普通话准确率验收。

## 使用

服务启动并取得独立语音凭据后，用PowerShell 7运行 `scripts/Start-CompanyModel.ps1 -Voice`；可加 `-Mode dev`。模型与语音地址分别默认为用户确认的公司主机8000/v1和独立8001，凭据分别输入，不保存到文件、界面或命令行参数。已有旧实例须先关闭。

打开「文本任务建议」，点击“开始录音”，结束后试听，也可导入16kHz单声道16bit PCM WAV。录音最长15秒，最短0.2秒；默认只存内存，点击“保存 WAV 用于评测”才会保存。仅选择文件或录音不会上传；“提交语音识别”才发送当前WAV到已配置ASR。

转写出现后，重点核对十五/五十、厘米/米、零点、时长和“不要/取消”等词，可直接修改。点击“采用核对后的文字”只填入原文；即使与上一句相同，也清理旧建议，仍需另点“解析任务建议”。此操作不是飞行许可。

清除、换录音/文件、离开页面、进入回放或后台失效时停止采集并丢弃旧语音结果。返回页面或重启不恢复录音/转写。录音权限仅在当前页面显式请求期间开放音频，视频和屏幕采集继续拒绝。取消不自动重发，服务器忙时由用户稍后重试。

## 接口与边界

- `state.voice`独立记录配置、当前请求ID/音频哈希/时长、pending/review/empty/error、转写、耗时和错误；configured只代表本地配置存在，不表示服务已部署或在线。
- 窄IPC仅接受ArrayBuffer音频，最多500000字节；本机 `POST /api/v1/voice/transcribe` 用audio/wav原始正文，`POST /api/v1/voice/clear`取消清空。其他本机JSON入口保持4096字节上限，无通用URL/HTTP/文件路径入口。
- 外部ASR调用固定 `/v1/transcriptions`；独立环境变量 `LF2S_ASR_BASE_URL` / `LF2S_ASR_TOKEN`。单请求40秒绝对期限、连接最多3秒、响应16KiB，不跟随重定向/环境代理，不重发。核对本次音频SHA、时长、CPU模型/zh、文本长度及所有禁止授权字段。
- 本机音频提交与清空经主进程排队，上传立即返回任务状态，识别异步进行；清空不会被迟到上传越过。回放打开先取消语音。日志仅记录哈希、时长、状态和耗时，不自动保存音频或转写正文；用户显式导出和单独评测记录另计。
- ASR与文本建议均无执行出口。转写的数字/否定词即使识别错了，也仍需人工核对、原文校验和未来正式执行链的许可/机载预检；本版不能证明任意语义都正确。

## 证据

`tests/test_voice.py`为36项故障/隔离注入测试。`tests/voice_desktop.cjs`通过真实Electron音频图、IPC与HTTP检查；麦克风使用Chromium测试音频设备，禁止冒称真人麦克风通过。`--real-asr`显式运行本机SenseVoice，使用官方中文样音；`--company-model`另需显式公司模型环境配置，验证人工修改后的文字经过实际无思考Qwen。

这类样音不是飞行口令，测试对原文的人工修改也不是ASR正确识别任务的证据。真实普通话录音清单和字错率/关键词核对工具位于研发工作区 `P1/09_语音服务/evaluation`；当前没有真人语料，不计算准确率或宣称选型最终通过。
