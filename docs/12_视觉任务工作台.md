# 视觉任务工作台

0.8.0默认打开工作台。左侧用于相机画面，右侧显示当前任务建议与对应识别字段，下方是文字/语音助手；右上角「设备与调试」进入原有详细功能。

## 日常入口

1. 通过「相机设置」进入ESP32台架，填写当前实际IPv4，显式连接后返回工作台查看图像。需要测试合成画面时选择「本机模拟」，再通过「模拟连接」显式建立本机模拟会话。没有自动连接设备。
2. 输入任务原文，或点「过马路」「清点纸币」填入示例。示例按钮不发送请求。
3. 点击「解析任务建议」。配置公司服务后只调用 `qwen38`，每次关闭思考；没有配置时显示原因。原文缺参、冲突或无法确定时先澄清。
4. 右侧核对理解与建议步骤。修改原文会清除旧建议。语音采用转写也只填入原文，需要另点解析。
5. 切到设备调试会清理工作台预览与当前建议，返回保留草稿并重新审阅。回放与服务失效不会继续展示旧实时结果。

## 两类演示的当前范围

「去路边，然后自己过马路」与「仅去路边」分别呈现过路和寻找路边建议。「去B点」只建议寻找收银台；「清点B点的人民币」才建议纸币清点。不同任务不能被缩减成起飞或查询状态，也不能凭空补高度/时长。

过路建议包含减速、观察、等待稳定绿灯、过路和到岸核对；纸币建议包含寻找收银台、停稳观察、识别平铺无遮挡人民币与核对合计。这些是需求流程，当前未连接视觉搜索、路径控制或动作执行。单次输入不能修改过路规则，也不能创建人工许可。

图像显示与识别结果独立。当前灯色、闪烁、斑马线、纸币张数、面额和总额均为未知；不会由文字建议填入绿色或金额。本机合成JPEG明确标注非实拍。公司ASR尚未部署，普通话录音和测试音频应分别验收。

## 设备与调试

原相机参数/对焦、原厂飞控USB只读、模拟状态、协议诊断、固定模拟任务、只读回放和日志继续使用原入口。显示连接成功不意味着实机控制可用。工作台无许可或真实飞行按钮，生产配置与实机资格保持原有隔离。
