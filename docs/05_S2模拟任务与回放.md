# S2 模拟任务与只读回放

本阶段沿用此前已确认的“现场人员在电脑界面明确允许后，电脑可申请自动解锁起飞”及现有协议动作语义。它只验证软件链路；没有打开真实设备、改写飞控内环或确定最终语音任务清单。

## 固定示例与完成证据

任务示例：模拟起飞至 500 mm → 保持 → 降落并上锁。500 mm、20 秒任务总预算、8 秒起降上限、300/500 ms 稳定窗口均为本机测试参数，不是实机场地配置。

默认监控仍使用未签认 profile。用户显式「重置并准备模拟器」后，模型更换 boot、断开旧会话，并仅在内存内具备 config_valid=1、validated_mask=1、可用启动代数、着地和预检的**合成测试假设**。原始 simulation/profile.json 仍为 0/0，production control_allowed / hardware_control_allowed 始终 false。此模拟资格不可导出当成实机签认。

1. 用户连接并查询当前模型配置。
2. 每次启动重新勾选模拟许可；后台绑定 boot/session/profile/calibration/reset，分配一次性 permit_id，发送 PERMIT(flags=1, scope=1)。
3. ACQUIRE 只授予控制权；BEGIN 登记独立递增任务号，不等于已经起飞。后台检查新状态、所有者、租期和任务编号。
4. TAKEOFF、HOLD、LAND 分别得到 IN_PROGRESS 和最终 COMPLETED。独立合成样本生产者按速度更新高度、armed、landed；FCModel 根据新的有效样本、误差和稳定时间产生完成。停止提供新样本会中断，单纯等待或 ACK 不会完成。
5. END 的任务最终结果与各动作结果分开；最后 RELEASE 撤权。续租仅在活跃流程中进行，不延长目标或任务期限。

没有开放任意位置、速度、任意动作 JSON 或裸 MAVLink 发送接口。任务入口只在本机模拟环境生效，用户不能给它传入真实地址。生产固件需要 S3 单独实现和验收。

## 异常、未知与接管

后台拒绝错误源/目标/消息/操作/任务/租期/会话结果。最终结果保持单调，迟到 ACCEPTED/IN_PROGRESS 不能覆盖；最终结果冲突记录为异常。

ACK 最多两次原字节重试，不能用新编号重新做未知动作。未知结果查询绑定原 boot/session/request_id；原会话已丢失时明确拒绝，不能用新会话冒充。取回一个动作结果只用于核实，不恢复旧流程或宣布任务整体成功。

断链、服务退出、定位 reset、样本失效、人工接管或人员取消停止顺序推进、续租及旧请求重试。模拟机载时钟在 PC 断开或网络暂停后继续前进，不能因电脑不轮询而冻结机载租期。任务、动作和租期到期分别由原模型检查。

模拟原遥控输入调用原模型的人工接管接口，锁存 MANUAL 并撤权。恢复健康场景、HELLO 和普通重连不清锁存；空中人工状态按现有协议可能拒绝 HELLO/BUSY。显式重置整个模拟器才开始新测试 boot，不能把它说成实机遥控器的解除步骤。真实解除条件仍待 S3 签认。

## 记录容量与时间轴

- 每次后台运行创建独立随机录制号。事件包含 run_id、boot/session/nonce、原请求、PC 接收单调时间、UTC 时间、source=synthetic、有效性/原因及结果。
- 快照最多 2 Hz、状态日志最多 1 Hz。图像只记有界元数据；不保存 JPEG 字节，回放明确提示没有历史图像，不混用实时图像。
- 录制队列最多 256 条，溢出丢弃新项并累计；单份最多 4 MiB，满后停止本次录制并累计丢弃。启动时删除最旧自有录制，含当前最多 6 份，总数据上限 24 MiB 加少量索引。界面展示丢弃、截断和写入错误；不把数据缺口补成测量。
- 写入在独立线程，状态抓取时复制可变对象；读取在有界线程任务中扫描最多 4 MiB，每次只返回一帧和此前最近 60 条事件。正常退出刷新索引；崩溃留下的部分 JSONL 可尝试读取完整行。

打开回放会断开实时会话，取消任务推进和续租；回放读取及时间轴播放从不发协议请求。实时连接、配置、场景、任务和图像端点全部拒绝，退出仍保持断开。回放显示历史采样年龄和当时有效性，常驻“历史合成数据”；其中 valid=true 不代表当前可控制。

## 后续边界

S3 才接真实 ESP32/STM32 和真实只读数据，再按条件验证控制与人工接管。S4 另做图像、中文语音和视觉，S5 保留 Mind+ 经手柄/NRF。没有数字签名、安装器或跨机验收；模型的故障状态不能证明真实飞机在所有失效场景都能悬停或降落。
