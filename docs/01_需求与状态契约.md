0.7.1结果关联补充：动作结果始终核对原消息/编号/操作/任务及会话。CANCEL/FAILSAFE的COMPLETED/OK和失败END(outcome=1)的FAILED/TASK可在撤权后携带零租期，且必须有最终事件编号；已失效租期的REJECTED也可携带0。其他非零租期不允许，缺最终事件编号的终结结果不能完成操作。零租期结果不是新的控制权，后续状态仍独立更新当前owner/lease。

## 状态维度

| 字段 | 含义与判定 |
| --- | --- |
| mode/simulation/read_only | mode=simulation/replay 时 simulation=true；mode=esp32_bench 时 simulation=false、read_only=true。显式任务模拟器 read_only=false；hardware_control_allowed 永远 false，真实出口仅为相机显示/诊断 |
| bench | 实物相机独立 active/phase/epoch/health/health_age_ms。飞控 link 与 identity 不由相机在线状态补造；实物台架传感器全部未知 |
| usb_fc / hardware_bench | 原厂 USB HID 只读数据独立呈现，simulation=false/read_only=true；接收年龄与采样年龄分开，未建立 MAVLink 会话。厂商原始状态不赋予控制资格；字段详见 docs/09 |
| bench.phase / last_error | 0.3.1 新增 recovering：临时传输失败清空显示状态，核对原配对流后恢复；连续三次失败进入 error。transport_failures/recoveries 记录计数，last_error 提供代码、端点、耗时与系统错误；流/身份错误立即阻断 |
| service_ready | 本地单 worker 已就绪；不说明飞机在线 |
| link.phase | disconnected → connecting → online；无新状态 1000 ms 为 stale；身份/指纹/重启校验失败为 blocked；主进程报告服务错误为 service_error |
| link.reconnect_required | 0.7.3起独立锁存检测到飞控重启后的显式重连要求；后续坏包/旧包不能清除，锁存时拒绝接收旧上下文和发送请求，显式断开清理后再新HELLO |
| link.state_age_ms | PC 单调时钟计算的最近有效 CONTROL_STATE 接收年龄；普通遥测/坏包不能刷新它 |
| identity | boot/session/nonce/期望与观测指纹；u64 全为十进制字符串，未建立用 null |
| sensors | 每项独立 valid/value/age_ms/reason/source/unit；模拟来源 synthetic，实物台架飞控未接入为 unavailable，value=null |
| qualification.configuration | 生产配置仍为 unknown 或 unsigned；默认 profile 的 config_valid=0、validated_mask=0；task_fixture=true 时动态使用 config_valid=1 / validated_mask=1，仅为本机模型测试假设 |
| qualification.control_allowed | 始终 false；不因连接、配置查询或传感器有效变为 true |
| hardware_freshness_qualified | 始终 false，JPEG 显示不产生实机新鲜度资格 |

1000 ms 链路、300 ms 传感器、2000 ms 图像显示预算均是本版**应用模拟参数**，没有被签认为实机控制指标。界面超过 1500 ms 没有收到主进程快照时自行失效所有测量。

姿态/位置/高度必须同时通过 CONTROL_STATE 的 valid_flags、FC 报告采样年龄加 PC 接收后年龄、对应 ATTITUDE/ODOMETRY 的本地接收年龄。年龄 0xFFFFFFFF 表示未知。电压通过 flags 与 65535 未知哨兵，不生成剩余电量百分比。停止更新测量时 FC 状态仍可在线，但传感器会失效；新收到包不等于测量新鲜。

ATTITUDE 单位 rad；ODOMETRY 严格接收 LOCAL_FRD(20)/BODY_FRD(12)，界面变换为 `(x,-y,-z)` 的场地 LOCAL_FLU，单位 m。没有 GPS 或真北地图。NaN/Inf 递归归一为 JSON null，不输出非法 JSON。0 可以是有效测量，未知不能用 0 代替。

## 只读操作与结果

应用 operation_id 为本地随机字符串，关联日志，不替代线协议 request_id。HELLO 与 QUERY_PROFILE 共用当前 Client 的 u32 业务编号。MAVLink seq 不充当业务身份。

本版操作状态 pending / accepted / rejected / unknown；附带原 protocol_phase。HELLO/配置查询的 ACCEPTED 只指只读请求应答，不标记飞行动作完成。配置查询需同时收到当前 boot/profile/calibration/reset 的 PROFILE 和对应 RESULT；同时最多一个查询。PROFILE 线消息没有 request_id，不能在应用里声称它带完整请求身份。迟到 PROFILE 只能作为同一配置版本的只读观测，未来涉及控制的配置读取仍须按权限/新鲜度重新检查。

ACK 超时 200 ms，最多 2 次原字节重试，总预算不超过 600 ms，受各请求 valid_ms 进一步限制。耗尽显示未知，不用新编号自动重复。默认监控出口只接受 HELLO / QUERY_PROFILE；显式本机任务模拟器额外开放固定任务白名单。没有通用 ACTION、裸 MAVLink 或 COMMAND_LONG 转发端点。

## S2 任务与历史状态

任务、原会话、配置/标定/reset、challenge、所有者/租期和新状态年龄分别校验。固定演示为 0.50 m TAKEOFF → HOLD → LAND；独立 TaskService 依序执行现场确认 → 一次性 PERMIT → ACQUIRE → BEGIN。每个动作最终完成由模型按新的有效合成测量产生，END 的任务最终结果独立记录，最后 RELEASE。续租不延长任务总预算或动作预算。

任务状态 pending / in_progress / completed / failed / cancelled / unknown / interrupted。原协议 ACCEPTED、IN_PROGRESS、COMPLETED 等保留在每项 operation 中。最终结果不能被迟到接受覆盖；未知结果只查询原 request_id，单个原动作结果取回不会恢复序列或宣布整项任务成功。中断停止续租和旧请求重试；普通重连、刷新和重启无自动任务恢复。人工接管锁存，普通重连不解除；空中状态可能拒绝 HELLO，显式重置整个模拟器才建立新 boot。

回放状态位于 replay，historical/read_only=true。其 sensors.valid/age_ms 是录制时的判定，不能当成当前有效性。实时 link 断开、测量失效；回放期间连接、任务、场景和图像端点拒绝。退出回放也不自动连接。详见 docs/05。

## 模拟场景

以下描述默认监控；任务模拟器另有独立合成运动生产者，模拟资格始终不代表硬件。健康场景由 `simulation/network.py` 显式生产静态合成场地坐标、高度、电压和微小姿态变化；不是编码器默认值，也不代表模型正在飞行。真实着地状态和预检保持未提供/无资格。所有未知场景将测量设为未知；冻结场景只停止测量生产，状态包继续更新；暂停链路丢弃全部模拟往返数据。错误指纹与来源是有意注入的负面用例。重启换 boot，必须显式断开后创建新会话。

模拟模型、网关和 PC 使用三个动态端口，全部只绑定 127.0.0.1，同处一个后台进程；模拟参数不能切入真实传输。新增实物台架使用独立、显式选择的HTTP provider；没有硬件串口或真实MAVLink控制出口，0.7.0普通话录音独立于车辆传输。

## 0.6.0 文本任务建议

`state.text_tasks`独立于车辆状态，记录当前原文、哈希、解析阶段、来源、耗时、原文数值依据及候选/澄清。按用户决定仅调用`qwen38`并显式关闭思考，拒绝思考字段；无单位/缺参先本地澄清，模型数值与原文不符时无候选。它不改变固定模拟任务参数、不创建许可或任何硬件动作，`executable/permission_granted/hardware_control_allowed`恒false。编辑/取消、进入回放和服务关闭清理旧建议，退出不恢复。公司ASR尚未部署，详见docs/10。

## 0.7.0 普通话语音审阅

`state.voice`记录独立音频请求和待核对转写，configured不等于在线。音频只在显式提交后送独立ASR；录音/试听/导入不触发上传，用户可显式保存WAV。采用转写只填入可编辑原文，即使文字相同也清空旧建议，另点解析才送无思考模型。语音入口、清理与软件/真人证据边界见docs/11。
